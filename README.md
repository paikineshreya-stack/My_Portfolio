# Personal Portfolio Website

## Project Title
Personal Portfolio Website – Shreya Paikine

## Project Description
This is a responsive personal portfolio website created to showcase my profile, technical skills, projects, and contact information as a web developer.

## Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive features
- Google Fonts – Poppins typography

## Features
- Responsive website design
- Home and About sections
- Skills and Projects sections
- Contact form interface
- Dark mode and light mode
- Mobile navigation menu
- Active navigation links
- Automatic current year display

## Project Structure

```text
personal-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Setup Instructions

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files (index.html, style.css, and script.js) are in the same folder.
4. Open index.html in your browser.
5. You can also use the Live Server extension in VS Code.
